# Ddove1

Source of https://divingdove1.github.io — TIL, TIF and write-ups from my reading.

- `content/`: published notes (`til/<topic>/`, `tif/`, `writeups/`, `pages/`), copied from my local notes folder when I publish.
- `build.py`: builds `_site/` (wikilinks, backlinks, topic pages, Atom feeds, TeX → MathML via KaTeX).
- `.github/workflows/publish.yml`: builds and deploys to GitHub Pages on every push to `main`.

Fonts (all SIL Open Font License): CMU Concrete, Neo Euler, Iansui (芫荽); licences in `static/fonts/`.
